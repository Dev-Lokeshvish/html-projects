Some Information

  • Sant kabirdas ji =
    1. Bhakti : Nirgun Bhagwan ki bhakti
    2. Pramukh rachna : Kabir ke dohe
    3. Pramukh shiksha : Pream , satya aur samaanta
    4. Bhakti ka roop : Bhakti aur gyaan

  • Sant Ravidas ji =
    1. Bhakti : bhagwan ke bhakti
    2. Pramukh rachna : Ravidas ji ke pad
    3. Pramukh shiksha : samaanta , pream aur bhaichara
    4. Bhakti ka roop : bhakti aur samarpan

  • Sant surdas ji =
    1. Bhakti : Shri Krishna ji ki bhakti
    2. Pramukh rachna : Sursagar
    3. Pramukh shiksha : Prem aur Bhagwan ke prati samarpan
    4. Bhakti ka roop : Krishna bhakti

  • Goswami tulsidas ji =
    1. Bhakti : Shri Ram ji ki bhakti
    2. Pramukh rachna : Ramcharitmanas
    3. Pramukh shiksha : Dharma , maryada aur kartavya
    4. Bhakti ka roop : Ram bhakti

  • Sant meera bai ji =
    1. Bhakti : Shri Krishna ki bhakti
    2. Pramukh rachna : Krishna Bhajan aur pad
    3. Pramukh shiksha : Prem , bhakti aur samarpan
    4. Bhakti ka roop : Krishna prem-bhakti
